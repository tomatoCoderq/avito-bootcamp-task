# Ориентация текста
### Садыков Хасан. Тестовое задание Avito
Для каждого из 20 000 кропов с текстом нужно предсказать вероятность того, что текст перевёрнут на 180°. Метрика: 1 − Brier.

Результат на закрытом тесте: 0.9737 (ошибка Брайера 0.0263).

Основной блокнот: [submission.ipynb](submission.ipynb)

## Решение

Модель PP-LCNet x1.0 из PaddleOCR, предобученная как раз на задачу «строка текста повёрнута на 0° или 180°». Я взял её готовые веса и дообучил на реальных фото с русским и английским текстом (датасеты ниже).

Главная идея: антисимметричная голова. Картинка $x$ и её поворот $Rx$ отличаются только знаком фазы спектра, а метки у них противоположные. Поэтому у правильного ответа $z(Rx) = -z(x)$. Модель сразу строится так, чтобы это выполнялось:

$$z(x) = \tfrac12\bigl[g(x) - g(Rx)\bigr], \qquad p_{180} = \sigma\!\left(\frac{z(x)}{T}\right),$$

где $g$ это логит «180° минус 0°» основной сети, а $T$ это температура, которая подбирается на валидации. Функция потерь: бинарная кросс-энтропия, исходный кроп считаем нормальным, его поворот перевёрнутым.

Итоговая модель экспортирована в ONNX в FP32 и FP16. FP16 даёт то же качество и работает быстрее.

## Данные

Датасеты для обучения:

* [RusTitW](https://www.kaggle.com/datasets/hardtype/rustitw-russian-language-visual-text-recognition): реальные фото с русским и английским текстом, рамки абзацев;
* [TextOCR](https://huggingface.co/datasets/MiXaiLL76/TextOCR_OCR): реальные кропы слов на английском.

Выданный тест использовался только для предсказаний: без разметки, без подбора порогов, температуры и модели.

## Результаты

Отложенная выборка, 1 − Brier после калибровки ($T = 1.171$). Clean означает кропы, у которых ширина не меньше высоты и есть хотя бы одна буква: для вертикальных кропов и кропов из одних цифр вопрос «0° или 180°» не имеет смысла.

| срез | 1 − Brier | AUC | ECE |
|---|---|---|---|
| RusTitW clean | 0.9761 | 0.9958 | 0.0060 |
| RusTitW, кириллица | 0.9782 | 0.9963 | 0.0069 |
| RusTitW, кириллица, 1 строка | 0.9730 | 0.9942 | 0.0110 |
| RusTitW, кириллица, многострочные | 0.9839 | 0.9983 | 0.0110 |
| RusTitW, латиница | 0.9651 | 0.9923 | 0.0144 |
| RusTitW, все кропы | 0.9583 | 0.9888 | 0.0049 |
| TextOCR clean | 0.9550 | 0.9827 | 0.0087 |
| TextOCR, все кропы | 0.9349 | 0.9710 | 0.0121 |

ECE показывает ошибку калибровки, насколько уверенность модели расходится с реальной долей верных ответов.

Для сравнения: константа 0.5 даёт 0.75, готовая PP-LCNet x1.0 без дообучения даёт 0.834 на RusTitW clean, а с усреднением по картинке и её повороту 0.887.

Размер и скорость на CPU Kaggle (onnxruntime, 1 поток, один кроп):

| версия | параметров | файл | мс/кроп |
|---|---|---|---|
| FP32 | 1.67M | 6.7 МБ | 17.1 |
| FP16 | 1.67M | 3.4 МБ | 12.7 |

## Как воспроизвести

Обучение рассчитано на Kaggle с GPU (T4), полный прогон занимает около 1.5 часа.

1. Создать ноутбук на Kaggle из `submission.ipynb`, включить GPU и Internet.
2. Добавить в Input датасет RusTitW и датасет с тестом (папка с `test_XXXXX.png`).
3. В `Config` указать путь к тесту (`avito_test`).
4. Run All.

В `/kaggle/working` появятся `submission.csv`, `model.pt`, `model.onnx`, `model_fp16.onnx`, `calibration.json` (температура и параметры предобработки) и `report.json` (метрики, история обучения, скорость).
